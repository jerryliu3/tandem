# Tandem Implementation Plan

> **For agentic workers:** Executed inline (superpowers:executing-plans) by the same agent that wrote
> the spec. Steps use checkbox (`- [ ]`) syntax. Engine tasks are strict TDD with the exact expected
> values below; UI tasks are verified by typecheck/build plus a browser pass.

**Goal:** Build Tandem, a local-first React dashboard that replaces the Finances.numbers sheet with
precise 2026–2027 Brooklyn/NYC tax math, cross-border condo modeling, budgets, projections, and a
retirement goal solver.

**Architecture:** Pure TypeScript engine (`src/engine`) computes everything from a single `Plan`
JSON document; Zustand store (immer + zundo undo) persists via a `PlanRepository`
(localStorage now, Supabase later); React UI renders pages with Recharts and Framer Motion.

**Tech Stack:** Vite, React 19, TypeScript (strict), Tailwind CSS v4 (`@tailwindcss/vite`),
`radix-ui`, Recharts 3, `motion`, Zustand 5 + `immer` + `zundo`, `lucide-react`,
`@fontsource-variable/inter`, Vitest.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-11-23-tandem-design.md` is the source of truth for all
  numbers (tax tables §5.1, formulas §5.2–5.9).
- All engine money math in USD; CAD converts at `fxCadPerUsd` (USD = CAD / fx).
- Engine functions are pure and never throw on user data.
- Single filer only. Plan years 2026 and 2027; later projection years index per spec §5.1.
- No derived values persisted. Plan has `schemaVersion: 1`.
- Node is at `~/.local/node/bin` (prefix commands with `export PATH="$HOME/.local/node/bin:$PATH"`).
- Commit after each task.

### Task 3: Federal tax + tables

**Files:** `src/engine/tax/tables.ts`, `brackets.ts`, `federal.ts`, `federal.test.ts`

**Produces:**
- `type Bracket = { upTo: number; rate: number }` (last `upTo: Infinity`).
- `scheduleTax(income, brackets, roundBases=false)`: progressive tax; with `roundBases`, cumulative
  base at each threshold is rounded half-up to whole dollars (NY/NYC convention).
- `marginalRateAt(income, brackets)`.
- `interface TaxTables { year; federal: {brackets, standardDeduction, ltcg0Max, ltcg15Max,
  saltCap, saltPhaseStart}; fica: {ssWageBase, ssRate, medicareRate, addlMedicareRate,
  addlMedicareThreshold, niitThreshold}; limits: {k401, k401CatchUp50, k401CatchUp6063, dc415c,

  hsaFamily, hsaCatchUp}; ny: {brackets, standardDeduction}; nyc: {brackets}; nyPayroll:

- `getTables(year: number, inflationPct: number): TaxTables` — 2026/2027 literal; years > 2027
  index federal/limits/SS base/Canada from 2027 by `(1+inflation)^(year−2027)` (round brackets to
  $25, limits to $500 for k401/ira/hsa per IRS rounding, SS base to $300); NY/NYC fixed; SALT per
  statute (×1.01/yr through 2029, $10,000 cap and no phase from 2030). Years < 2026 use 2026.
- `federalIncomeTax(taxable, t)`, `saltCapFor(magi, t)` (cap − 30%·(magi − start), floor 10,000).

      `getTables(2030,2.5).federal.saltCap === 10000`; `getTables(2028,2.5).federal.standardDeduction > 16600`;
